# 个人IP军师团 · 公开界面展示版

这是一个无需登录的静态界面展示，用于了解产品的布局、角色和工作流程。不是已上线的真实AI服务。

## 可以体验

- 在八位军师之间切换视角，查看职责与任务帮助。
- 手动填写、修改和确认IP档案，创建多个本浏览器项目。
- 记录选题、发布检查、总军师诊断卡、作品设计与拍摄卡和作品级复盘。
- 在“我的IP档案”中导出自己填写的项目JSON；检查和复盘的文字导出仍可使用。

推荐顺序：对话起步 → 我想直接填表 → 确认资料 → 总军师诊断 → 作品工作台 → 作品级复盘。

## 明确未启用

真实AI聊天、自动提取档案、单席分析、全团分析和服务器PDF报告。相关入口会禁用或展示能力说明，不会伪造AI回复或PDF文件。起步问候是固定提示文案。

## 数据与隐私

填写的档案和工作记录仅保存在自己的浏览器，不发送给模型或服务器，也不会进入GitHub仓库。不同访客不会看到彼此的记录。清理浏览器会导致记录丢失；同一浏览器的项目不是登录账号隔离，不要在共用电脑输入敏感信息。网页文件本身由GitHub Pages提供；本展示版不包含自建分析、模型密钥或后台。

## 产品边界

八军师是工作视角，不是持续在后台运行的自治代理。作品卡由你填写；真实拍摄、平台数据、事实和素材授权都需要你自行确认，不提供流量或经营效果保证。
